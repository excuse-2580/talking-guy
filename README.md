# 会说话的小人

打字或说话，他都替你讲出来。

## 在线玩

https://excuse-2580.github.io/talking-guy/

## 功能

- **打字朗读**：输入文字，点「🔊 说出来」，小人开口讲话
- **语音闭环**：点 🎤 说话 → 自动转成文字 → **小人立刻把你刚说的念出来**
- **快捷短语**：6 个预设，点一下就说
- **点小人**：也能让他说话
- 说话时嘴巴张合、身体摆动、手臂挥动，并显示语音气泡

快捷键：`Ctrl/Cmd + Enter` 朗读；「■ 闭嘴」随时打断。

## 技术

纯前端单文件，基于浏览器原生 **Web Speech API**：
- `SpeechSynthesis` 负责朗读（自动挑选中文音色）
- `SpeechRecognition` 负责语音识别（`zh-CN`）
- 识别结果加 420ms 防抖，只在**完整句**（`isFinal`）时才朗读，避免边说边读

无框架、无外部依赖、无后端。

## 隐私说明（重要）

- **朗读（🔊）在本地完成**，不联网、不上传。
- **语音识别（🎤）由浏览器实现**：Chrome / Edge 会把音频发到云端（Google）识别，
  这是浏览器行为，网页无法阻止。Firefox 等实现各有不同。
- 若你不希望音频出设备，请不要点 🎤，只用打字 + 🔊 即可，功能完全可用。

## 兼容性说明

- 语音合成与识别依赖浏览器支持，各浏览器差异较大
- 🎤 麦克风通常只在 **https** 或 localhost 下可用（本地双击打开会被拦）
- 若设备没有中文音色，可能读不出中文，此时文字仍会显示在气泡里
- 页面底部会实时提示当前环境支持哪些能力
